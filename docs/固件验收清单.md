# kwrt-ax1800 固件验收清单

> 用途：新镜像刷上后，逐项确认「能用、够快、不会偷偷坏」。
> 分五块：刷机方式 → 首启即验 → 功能验收 → 性能 → 稳定性/回归。
> 每项给「命令 / 方法」和「期望值」。已能自动化的用 `scripts/self-check.sh` 一键跑。

---

## 0. 刷机方式（先决）

| 场景 | 命令 | 说明 |
|---|---|---|
| 干净刷（首刷/换 target） | `sysupgrade -n /tmp/xxx-sysupgrade.bin` | `-n` 不保留旧配置，排除旧设置干扰 |
| 日常升级 | `sysupgrade /tmp/xxx-sysupgrade.bin` | 保留 overlay 配置 |

⚠️ 本机是 eMMC，`/proc/mtd` 为空，**不要用 `mtd write` 刷分区**，只用 `sysupgrade`。

---

## 1. 首次开机即验（约 5 分钟，刷完立即做）

| # | 检查项 | 命令 / 方法 | 期望 |
|---|---|---|---|
| 1.1 | 有线能进后台 | 浏览器开 `http://192.168.1.1`，SSH `root@192.168.1.1` | LuCI 出来、能登录 |
| 1.2 | 版本 / target | `cat /etc/openwrt_release` | `25.12-SNAPSHOT`、`qualcommax/ipq60xx` |
| 1.3 | 内存 / 闪存报告合理 | `free`；`df -h /` | 约 878MB / rootfs 2.0G |
| 1.4 | banner 居中 | 登录 SSH 看首屏 | 猫居中、机型/版本行对齐 |
| 1.5 | root 密码 | 用 Secret 登录 | 能进（不是默认 root） |
| 1.6 | 时间同步 | `date` | 年份正确（NTP 已同步 = 能出网） |
| 1.7 | 无线自动好 | `ls /sys/class/ieee80211/` | **首启即出 `phy0 phy1`**（关键回归点） |
| 1.8 | cal 自动生成 | `ls -l /lib/firmware/ath11k/IPQ6018/hw1.0/` | `cal-ahb-c000000.wifi.bin` 存在（65536 字节） |

## 2. 功能验收（本项目定制点，逐个确认）

| # | 检查项 | 命令 | 期望 |
|---|---|---|---|
| 2.1 | 无线 SSID | `uci -q show wireless | grep ssid` | `ssid='CLI'`，2.4G+5G 都有 |
| 2.2 | 无线加密 | `uci -q show wireless | grep encryption` | `psk2` |
| 2.3 | hostapd 在跑 | `ps w | grep -q hostapd` | 有进程 |
| 2.4 | DNS rebind 保护 | `uci -q get dhcp.@dnsmasq[0].rebind_protection` | `1` |
| 2.5 | DNS 本地服务 | `uci -q get dhcp.@dnsmasq[0].localservice` | `1` |
| 2.6 | DNS 重定向 | `uci -q get dhcp.@dnsmasq[0].dns_redirect` | `0` |
| 2.7 | BBR 拥塞 | `sysctl -n net.ipv4.tcp_congestion_control` | `bbr` |
| 2.8 | NSS 硬件加速 | `lsmod | grep -E 'ecm|qca_nss_drv'` | 两个都在 |
| 2.9 | iStore 顶替菜单 | LuCI「系统 → Software」 | 打开是 iStore，不是官方 package 页 |
| 2.10 | 无线菜单 | LuCI「网络 → 无线」 | 能看到 radio0/radio1 |
| 2.11 | DHCP 分配 | 手机/电脑连上后 `ifconfig` | 拿到 `192.168.1.x` |
| 2.12 | 出网（WAN） | `ping 223.5.5.5`、`ping www.baidu.com` | 通（IP + 域名都通 = 路由 + DNS 正常） |

> 2.4–2.7、2.8 是 `ab881b2`/A1 的改动，**旧镜像上会显示相反值**，务必以新镜像为准。

## 3. 性能测试（可选，需要 iperf3）

| # | 项 | 方法 | 参考标准 |
|---|---|---|---|
| 3.1 | 内网吞吐 | 两端 `iperf3`：PC `iperf3 -s`，另一台 `iperf3 -c <PC> -t 20` | 有线 1G 口接近线速；WiFi 2.4G ~80Mbps / 5G ~400Mbps 量级 |
| 3.2 | 延迟 | `ping 192.168.1.1 -n 50` | 有线 <1ms；WiFi <10ms |
| 3.3 | 丢包 | `ping 192.168.1.1 -n 300`（5 分钟） | 0% 丢包 |
| 3.4 | 信号强度 | 手机 Wi-Fi 分析 App / LuCI 概览 | 附近 -40~-60 dBm 为佳，弱于 -70 留少余量 |
| 3.5 | 出网测速 | Speedtest 网页 | 接近宽带签约速率 |

---

## 4. 稳定性（soak，网上一再强调的重点）

| # | 项 | 方法 | 判据 |
|---|---|---|---|
| 4.1 | 长时间运行 | 连续开机 ≥72 小时，正常使用 | 无自动重启、无掉线 |
| 4.2 | 内存泄漏 | 每天 `free` 记一次 | used 不随时间单调上涨 |
| 4.3 | 内核错误 | `dmesg | grep -iE 'oops|panic|oom|timed out|failed'` | 无 OOM/驱动超时 |
| 4.4 | 系统日志 | `logread | grep -iE 'error|fail|warn'` | 无新增报错（`firmware-2.bin` 那条是无害噪音，可忽略） |
| 4.5 | 压力 | 多设备同时刷视频/下载/游戏 | 不卡、不掉速 |

## 5. 回归矩阵（每次改固件后重跑）

| 改动 | 必须重验 |
|---|---|
| banner / 概览页 | 1.4、LuCI 概览 |
| 99-ax1800（WiFi/cal） | 1.7、1.8、2.1–2.3 |
| my-default-settings（DNS/密码） | 1.5、2.4–2.6 |
| .config（BBR/加速） | 2.7、2.8 |
| 菜单（iStore/摘包） | 2.9、2.10 |

---

## 一句话总结

- **能自动化的**：`scripts/self-check.sh`（banner、机型、密码、DNS 三项、BBR、NSS、无线、存储内存、菜单、监听、时间）。
- **必须人肉的**：真机搜 SSID、连上测速、多设备并发、72 小时 soak —— 这些是脚本替不了、但网上最强调的部分。
